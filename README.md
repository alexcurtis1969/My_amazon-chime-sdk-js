# Amazon Chime SDK Meeting Demo
# This code block is still in testing

This project provides a simple web application that demonstrates how to use the Amazon Chime SDK to create and join meetings.

## Features

* **Create meetings:** Create new meetings with a server-side API.
* **Join meetings:** Join existing meetings using a meeting ID.
* **Basic UI:** Provides a simple user interface with buttons to create and join meetings.

## Architecture

The application consists of two main components:

* **Frontend:** A static HTML page with JavaScript that interacts with the backend API.
* **Backend:** An Express.js server that handles meeting creation requests using the Amazon Chime SDK.

## Prerequisites

* **Node.js and npm:** Make sure you have Node.js and npm (or yarn) installed on your system.
* **AWS Account:** You'll need an AWS account with access to the Amazon Chime SDK.
* **AWS Credentials:** Configure your AWS credentials (access key ID and secret access key) locally or use an IAM role.
